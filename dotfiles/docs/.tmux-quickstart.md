# tmux quickstart — this config

Prefix is `C-a`, not `C-b`. Press and release it, then the key. `C-a C-a` sends a literal
`C-a` through to the program underneath.

Windows count from 0, panes from 1. The mouse works: click a pane to focus it, drag a border
to resize, scroll to enter copy mode.

Most of what you reach for daily has no prefix at all — it is on Alt.

---

## No prefix — the keys worth learning first

| Keys | Does |
|---|---|
| `M-o` | **Project picker.** fzf over your project roots; attaches the session if it exists, creates it if not. One session per directory. |
| `M-s` | **Scratch shell.** A floating popup on the `_scratch` session — always the *same* one, so it keeps its history and whatever you left running. `M-s` again closes it. |
| `M-h` `M-j` `M-k` `M-l` | Move left/down/up/right — across tmux panes *and* nvim splits, one grid. Works in copy mode too. |
| `M-H` `M-J` `M-K` `M-L` | Resize by one cell. Hold to repeat. |
| `M-[` `M-]` | Previous / next window. |
| `M-0` … `M-9` | Jump straight to that window. |
| `M-\` | Enter copy mode. |

`M-o` and `M-s` are the two that change how you work. The rest is muscle memory.

## With the prefix

| Keys | Does |
|---|---|
| `C-a \|` | Split left/right, in the current pane's directory |
| `C-a -` | Split top/bottom, same |
| `C-a c` | New window, same |
| `C-a h/j/k/l` | Select pane (the no-prefix `M-` versions are usually better) |
| `C-a F` | **Command search** — fuzzy-find every tmux command with its description and a live man-page preview |
| `C-a ?` | This file |
| `C-a g` | **Jump to text on screen** — labels every path, URL and hash; press the label to copy it |
| `C-a Tab` | **Grab from scrollback** — fuzzy-pick a word or line out of what has already scrolled past |
| `C-a r` | Reload `~/.tmux.conf` |
| `C-a :` | tmux command prompt — `cheat` is an alias for `C-a F` |

`"` and `%` are unbound on purpose, so a mistyped split does nothing rather than the wrong
thing. `C-Left`/`C-Right`/`C-Up`/`C-Down` are unbound too — they belong to the shell.

## Copy

Selection goes to the macOS clipboard automatically (`set-clipboard on`, plus tmux-yank).
`M-\` enters copy mode, `v` starts a selection, `y` yanks, `q` leaves. Scrollback is 10,000
lines.

For anything you can already see, `C-a g` beats selecting by hand. For anything that has
scrolled away, `C-a Tab`.

## Reading the status bar

**The window tab tells you what the pane is doing**, rather than naming the program:

| Tab shows | Means |
|---|---|
| `▶ pytest -x` | that command is running now |
| `✔ pytest -x` | it finished cleanly |
| `✘1 cargo build` | it exited 1 |
| `✎:punto/README.md` | nvim, editing that file |
| `~` or a directory name | an idle shell |

So a background window that has gone `✘` is visible without switching to it.

**The session name sits far left** and turns yellow while the prefix is armed — if you are
not sure whether tmux swallowed your last keystroke, look there.

## Claude Code in this setup

Three things are wired, none of which tmux does on its own:

- **The statusline under your prompt** is Claude Code's, coloured to match the agnoster
  prompt above it, so the two read as one bar. It shows model, effort, context percentage
  and both rate-limit windows.
- **The window tab** shows Claude Code's session name, so a tab running Claude is
  identifiable from the bar.
- **`claude-notify.sh` nudges you** when Claude wants permission or has finished — but only
  when its pane is in the background. If you are looking at it, you already know.

Two panes side by side is the usual shape: `C-a |`, then `claude` in one and a shell in the
other, `M-h`/`M-l` between them. For two independent Claudes, use two *sessions* via `M-o`
rather than two panes — each keeps its own directory and history.

## When something looks wrong

| Symptom | Cause |
|---|---|
| Boxes instead of glyphs | terminal is not set to the Nerd Font |
| Colours look flat under tmux | `CLAUDE_CODE_TMUX_TRUECOLOR=1` is not exported |
| A key does nothing after editing the config | `C-a r` only *adds* bindings; removing one needs `tmux kill-server` |
| `M-o` shows the wrong projects | `TMUX_SESSIONIZER_ROOTS` in `~/.config/punto/machine.zsh` |
