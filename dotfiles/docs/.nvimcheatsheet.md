# Neovim Cheatsheet
Leader = Space

─── FIND / SEARCH ANYTHING ───────────  ─── BUFFERS & WINDOWS ────────────────  ─── NEW FILES & BUFFERS ──────────────
  Space ff       Find files               S-L / S-H      Next / prev buffer       Space ns       New file, vsplit
  Space fg       Grep the project         Space bd       Close buffer             Space nS       New file, hsplit
  Space fb       Open buffers             M-h/j/k/l      Split OR tmux pane       Space nb       New buffer, vsplit
  Space fr       Recent files             C-h/j/k/l      Split only               Space nB       New buffer, hsplit
  Space fw       Word under cursor        Spc sv / sh    Split vert / horiz
  Space /        Search this buffer       Space sx       Close split              ns/nS open the cmdline at
  Space fk       ALL keymaps              C-arrows       Resize split             the current file's dir —
  Space fc       ALL commands                                                     Tab pops up a file menu.
  Space fh       ALL help

─── EDITING ──────────────────────────  ─── NAVIGATION & CURSOR ──────────────  ─── SEARCH & REPLACE ─────────────────
  jk             Exit insert mode         gg / G         Top / end of file        /  ?           Search fwd / back
  C-s            Save (any mode)          { / }          Prev / next para         n / N          Next / prev match
  u / C-r        Undo / redo              w / b          Next / prev word         * / #          Word under cursor
  gcc / gc       Comment line / sel       e / ge         End of word fwd/bk       Esc            Clear highlight
  v / V / C-v    Vis / line / block       0 / $          Start / end of line      :s/old/new     Replace in line
  y / p          Yank / paste             f / F          Find char fwd/back       :%s/old/new/g  Replace in file
  p (visual)     Paste, keep yank         t / T          Till char fwd/back       :%s/old/new/gc Replace, confirm
  d / x          Delete / del char        ; / ,          Repeat last f / t
  c              Change (del + ins)       C-o / C-i      Jump back / forward
  J / K (vis)    Move selection           C-d / C-u      Page down / up
  < / > (vis)    Indent left / right      zt / zz / zb   Cursor top/mid/bottom
  ~              Toggle case
  gu / gU        Lower / uppercase
  Space cf       Format file (LSP)
  Space gq       Toggle soft wrap

─── FILE TREE (NEO-TREE) ─────────────  ─── LSP / DIAGNOSTICS ────────────────  ─── COMPLETION POPUP ─────────────────
  Space e        Toggle tree              K              Hover docs               C-Space        Trigger completion
  Space o        Focus tree               gd / gD        Definition / decl        C-j / C-k      Next / prev item
  Enter / o      Open file                gr / gi        Refs / impl              Tab / S-Tab    Cycle items
  s / S          Open in v / h split      Space k        Signature help           Enter          Confirm selected
  t              Open in new tab          Space rn       Rename symbol            C-e            Abort
  a / A          New file / dir           Space ca       Code actions             C-b / C-f      Scroll doc window
  d / r          Delete / rename          Space fs / fS  Doc / wksp symbols
  c / m          Copy / move              ]d / [d        Next / prev problem
  H              Toggle hidden            Space d        Show diagnostic
  ?              Show tree binds

─── TEXT OBJECTS ─────────────────────  ─── REGISTERS ────────────────────────  ─── MACROS ───────────────────────────
  ciw / caw      Change in/around word    "ayy           Yank line to reg a       qa             Record into reg a
  ci( ci{ ci[    Change in brackets       "ap            Paste from reg a         q              Stop recording
  ci" ci'        Change inside quotes     "0p            Paste last YANK          @a             Replay macro a
  cit / cat      Change in/around tag     "_d            Delete to black hole     10@a           Replay 10 times
  vip / vap      Select in/around para    :reg           List all registers       @@             Replay the last macro
  dap            Delete a paragraph       C-r a          Insert reg a (insert)    qA             Append to macro a
  ya(            Yank parens+contents     y already hits the system clipboard     :reg a         Inspect / edit it
  i vs a         inside vs around                        so d clobbers it too     V :normal @a   Run on a selection

─── MARKS ────────────────────────────  ─── GLOBAL — :g ──────────────────────  ─── QUICKFIX ─────────────────────────
  ma             Set mark a (in file)     :g/pat/d       Delete matching lines    Space fg       Grep, then C-q
  `a             Jump to mark a           :v/pat/d       Delete NON-matching      C-q            Telescope -> quickfix
  'a             Jump to its line         :g/pat/normal  ...then keys, e.g. A;    :copen :cclose Open / close list
  mA             Global mark, any file    :g/pat/m$      Move matches to end      :cn / :cp      Next / prev entry
  ``             Back to pre-jump spot    :g/pat/t$      Copy matches to end      :cdo s/a/b/g   Run on every entry
  `.             Last edit position       :g/pat/s//x/g  Sub on matches only      :cfdo %s/a/b/g Run once per file
  `^             Last insert position     :%s//new/g     Reuse last search pat    :cfdo update   Save changed files
  :marks         List all marks                                                   :cc N          Jump to entry N

─── DIFFVIEW — two-ref diffs ─────────
  Space gv       Diff working tree
  Space gr       Diff against a ref
  Space gh       History: this file
  Space gH       History: whole repo
  Space gV       Close diffview
  :DiffviewOpen  a..b, HEAD~3, main
  <tab> S-tab    Next / prev file
  g?             Diffview's own keys
